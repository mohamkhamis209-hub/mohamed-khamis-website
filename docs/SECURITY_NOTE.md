# ملاحظة أمنية

تم تضمين مفتاح ImgBB في `assets/js/config.js` بناءً على طلب مالك الموقع. أي مفتاح موجود في JavaScript عام يمكن استخراجه من GitHub أو أدوات المتصفح واستخدامه من الآخرين. راقب استهلاك ImgBB ودوّر المفتاح إذا ظهر استخدام غير معتاد.

حظر F12 وكليك يمين وبعض الاختصارات يمنع بعض الاستخدامات العادية فقط. لا يمكن تقنياً إخفاء كود موقع ثابت عام أو منع المستخدم من فتح أدوات المطور بطرق أخرى. حماية بيانات الإدارة تعتمد على Firebase Authentication وقواعد Firestore، وليس على حظر أدوات المطور.
